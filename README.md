Odoo BIOZON:

## DESCRIPTION:  

Este repositorio contiene el módulo personalizado de Odoo desarrollado para el proyecto Biozon.<br>
El objetivo de este módulo es añadir nuevas funciones, creando modelos, vistas y menús adaptados a las necesidades del proyecto.<br>
El módulo está organizado de forma sencilla y clara para que cualquier persona pueda entender cómo funciona. <br>
<br>
Incluye:<br>
- Nuevos modelos para gestionar información específica del proyecto.<br>
- Vistas personalizadas (formularios, listas y kanban) para mostrar los datos de manera más visual y práctica.<br>
- Menús y submenús propios, integrados dentro de Odoo para acceder fácilmente a cada parte del módulo.<br>
- Herencias de vistas y modelos, que permiten modificar partes de Odoo sin romper su funcionamiento.<br>
- Un pequeño controlador API, que devuelve datos en formato JSON desde el navegador, mostrando cómo se puede ampliar Odoo hacia el exterior.<br>
<br>
La estructura del módulo está pensada para que sea fácil de mantener y ampliar en el futuro, permitiendo añadir nuevas funciones sin complicar el código.

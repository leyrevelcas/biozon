MÓDULO Odoo BIOZON:
DESCRIPTION:  
Este repositorio contiene el módulo personalizado de Odoo desarrollado para el proyecto Biozon.
El objetivo de este módulo es añadir nuevas funciones, creando modelos, vistas y menús adaptados a las necesidades del proyecto.
El módulo está organizado de forma sencilla y clara para que cualquier persona pueda entender cómo funciona. 

Incluye:
Nuevos modelos para gestionar información específica del proyecto.
Vistas personalizadas (formularios, listas y kanban) para mostrar los datos de manera más visual y práctica.
Menús y submenús propios, integrados dentro de Odoo para acceder fácilmente a cada parte del módulo.
Herencias de vistas y modelos, que permiten modificar partes de Odoo sin romper su funcionamiento.
Un pequeño controlador API, que devuelve datos en formato JSON desde el navegador, mostrando cómo se puede ampliar Odoo hacia el exterior.

La estructura del módulo está pensada para que sea fácil de mantener y ampliar en el futuro, 
permitiendo añadir nuevas funciones sin complicar el código.
